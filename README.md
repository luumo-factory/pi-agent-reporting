# Pi Agent Reporting

A powerful tool for monitoring and viewing reports generated by [Pi](https://pi.dev) coding agents.

## Overview

This application provides a live monitoring interface for reports generated by Pi agents. It watches a local directory for new Markdown files, automatically detects changes, renders them with proper styling and syntax highlighting, and presents them in a clean, modern web interface.

### How It Works

1. **File System Monitoring**: Continuously scans the configured reports directory (default: `/home/timothy/reports/`) for new or updated Markdown files
2. **Automatic Rendering**: Converts Markdown to HTML using CommonMark with GitHub Flavored Markdown support
3. **Live Web Interface**: Serves reports through a responsive web UI on port 9000 with automatic refresh
4. **Theme Support**: Full dark/light mode support with automatic detection

### Integration with Pi Agents

To enable automatic report generation, add these instructions to your Pi agent's system prompt:

```markdown
If you need to show me anything complicated or summarise your work, you should write 
out a report in **Markdown format** to /home/timothy/reports/ with a date and simple summary, 
for example `2026-10-05_list_of_issues_found.md`.

If you are working on a specific project, you should put the report in a subfolder
with the project name. If it's not clear, just put them directly in the 'reports' folder.

Markdown reports are automatically rendered with proper styling, syntax highlighting, and theme support.
Just write clean, well-structured Markdown. Make sure to provide excellent summaries of what has happened,
so that it is easy to review.

Always write out a report for anything non-trivial, so that it is easier for me to review.
```

### Key Features

- **File System Monitoring**: Automatically scans the reports directory for new or updated Markdown reports
- **Server-Side Rendering**: Markdown files are rendered to HTML using CommonMark with GitHub Flavored Markdown support
- **Live Updates**: Reports list refreshes automatically without page reload
- **Dark Mode**: Full theme support with automatic detection and manual toggle
- **Modern UI**: Clean, responsive interface with smooth transitions
- **No Database Required**: Works directly with files on the filesystem
- **Syntax Highlighting**: Automatic code block highlighting for multiple languages

## Technology Stack

- **Java 25** (OpenJDK 25) with Records
- **Spring Boot 4.0.6**
- **Thymeleaf** for server-side rendering
- **CommonMark** for Markdown parsing
- **Maven** for dependency management
- **No Lombok** - uses pure Java 25 features including records

## Configuration

The application can be configured via `src/main/resources/application.properties`:

```properties
# Server port
server.port=9000

# Reports directory to monitor
app.reports.directory=/home/timothy/reports

# Scan interval in milliseconds
app.reports.scan-interval=2000
```

## Building and Running

### Prerequisites

- Java 25
- Maven 3.9+

### Build the application

```bash
mvn clean package
```

### Run the application

```bash
mvn spring-boot:run
```

Or run the JAR directly:

```bash
java -jar target/pi-agent-reporting-1.0.0-SNAPSHOT.jar
```

The application will start on `http://localhost:9000`

## Usage

### For Agents

Agents can write reports to the configured directory (default: `/home/timothy/reports/`) in Markdown format.

**File naming convention:**
```
YYYY-MM-DD_description-with-hyphens.md
```

Example:
- `2026-05-13_system-updates.md`
- `2026-05-13_security-audit.md`

### For Users

1. Open `http://localhost:9000` in your browser
2. Reports will appear in the left sidebar
3. Click on a report to view it
4. Use the theme toggle to switch between light and dark mode

## API Endpoints

### REST API

- `GET /api/reports` - Returns JSON array of all reports
- `GET /api/reports/{filename}` - Returns the rendered HTML content of a specific report

### Response Format

```json
[
  {
    "filename": "2026-05-13_system-updates.md",
    "title": "System Updates",
    "date": "2026-05-13",
    "lastModified": "2026-05-13T15:30:00",
    "type": "markdown",
    "description": "system updates"
  }
]
```

## Markdown Support

Markdown files are automatically converted to HTML using the CommonMark library with support for:

- GitHub Flavored Markdown tables
- Autolinks
- Standard Markdown syntax

Markdown reports are wrapped in the same template styling as HTML reports for consistency.

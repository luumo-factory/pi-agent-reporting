# Pi Agent Reporting

A Spring Boot web application for managing and viewing reports generated by Pi coding agents.

## Overview

This application provides a live monitoring interface for reports generated by Pi agents. It watches a local directory for new HTML and Markdown files, automatically detects changes, and presents them in a clean, modern web interface.

### Key Features

- **File System Monitoring**: Automatically scans the reports directory for new or updated reports
- **Dual Format Support**: 
  - HTML reports are served directly
  - Markdown reports are rendered to HTML server-side using CommonMark
- **Live Updates**: Reports list refreshes automatically without page reload
- **Dark Mode**: Full theme support with automatic detection and manual toggle
- **Modern UI**: Clean, responsive interface with smooth transitions
- **No Database Required**: Works directly with files on the filesystem

## Technology Stack

- **Java 25** (OpenJDK 25)
- **Spring Boot 4.1.0**
- **Thymeleaf** for server-side rendering
- **CommonMark** for Markdown parsing
- **Maven** for dependency management

## Configuration

The application can be configured via `src/main/resources/application.properties`:

```properties
# Server port
server.port=8080

# Reports directory to monitor
app.reports.directory=/home/timothy/reports

# Scan interval in milliseconds
app.reports.scan-interval=2000
```

## Building and Running

### Prerequisites

- Java 25
- Maven 3.9+

### Build the application

```bash
mvn clean package
```

### Run the application

```bash
mvn spring-boot:run
```

Or run the JAR directly:

```bash
java -jar target/pi-agent-reporting-1.0.0-SNAPSHOT.jar
```

The application will start on `http://localhost:8080`

## Usage

### For Agents

Agents can write reports to the configured directory (default: `/home/timothy/reports/`) using either HTML or Markdown format.

**File naming convention:**
```
YYYY-MM-DD_description-with-hyphens.{html|md}
```

Example:
- `2026-05-13_system-updates.html`
- `2026-05-13_security-audit.md`

### For Users

1. Open `http://localhost:8080` in your browser
2. Reports will appear in the left sidebar
3. Click on a report to view it
4. Use the theme toggle to switch between light and dark mode

## API Endpoints

### REST API

- `GET /api/reports` - Returns JSON array of all reports
- `GET /api/reports/{filename}` - Returns the rendered HTML content of a specific report

### Response Format

```json
[
  {
    "filename": "2026-05-13_system-updates.html",
    "title": "System Updates",
    "date": "2026-05-13",
    "lastModified": "2026-05-13T15:30:00",
    "type": "html",
    "description": "system updates"
  }
]
```

## Markdown Support

Markdown files are automatically converted to HTML using the CommonMark library with support for:

- GitHub Flavored Markdown tables
- Autolinks
- Standard Markdown syntax

Markdown reports are wrapped in the same template styling as HTML reports for consistency.
